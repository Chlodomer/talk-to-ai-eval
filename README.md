# איך מדברים עם בינה מלאכותית · משימת הערכה

אתר סטטי בעברית (ללא שרת). הסטודנטים קוראים תיק עבודה של שישה מסמכים, גוררים קטעים ואבני בניין לפרומפט, כותבים משפטים משלהם, מגדירים הצלחה ומורידים קובץ TXT להגשה במערכת הקורס.

- `index.html`, `style.css`, `app.js`: הממשק
- `data.js`: התדריך, המסמכים, אבני הבניין ושאלות הסיכום (לעריכה)

הפריסה: GitHub Pages מענף `main`, מהתיקייה הראשית.
מפתח הבדיקה אינו במאגר הזה בכוונה.
